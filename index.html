PREFERENCES

Settings

Personalize the workspace and configure how the assistant behaves.

Appearance

Choose a theme or fine-tune the interface.

Layout & controls

Set up the app to match the way you work.

Language & voice

Choose the primary navigation language, voice input language and optional AI response language. Conversation text follows the model language.

Voice support

Speech input depends on the speech-recognition service available in your operating system and Electron build. It may not be offline. Text-to-speech uses installed system voices.

Privacy & permissions

Conversation history, projects and memory are stored locally. Prompts are sent to the configured model server. Connected MCP servers receive tool requests you approve by configuring them.

Screen snapshots

Screen sharing is a one-time, user-selected capture. The app does not monitor the screen continuously.

File workspaces

File reads are limited to the folder you select. Each file modification requires a confirmation and creates a backup.

Data & backup

Export a backup before moving the app to another computer.

A backup includes chats, projects, tasks, reusable workflows, saved memories, appearance profiles, benchmarks and preferences. It excludes attached image binaries, API keys and files in your workspace.

This keeps your selected workspace folder and registered MCP connections. Remove those separately in Connections.
